Shared database (recommended)

A real database so every phone reads and writes the same data. Free, and two people submitting at once no longer overwrite each other.

Not connected — data stays on this device
Setup (one time, about 3 minutes):
1. Make a free account at supabase.com and create a project
2. Open SQL Editor → New query, paste the setup SQL (button below), click Run
3. Open Settings → API and copy the Project URL and the anon public key
4. Paste them here and press Connect

The anon key is meant to be public, but with these settings anyone holding it can read and change troop data — share it only inside the troop.

Older sync method (GitHub file)

Only needed if you set this up before. The database above replaces it.

Multi-device sync (GitHub)

Store shared data in a GitHub repo so every device sees the same tickets. Free, no extra accounts.

Not connected — data stays on this device only
Setup:
1. Create a private repo on GitHub (e.g. troop-data)
2. Go to Settings → Developer settings → Fine-grained tokens
3. Generate a token: select only that repo, grant Contents: Read and write
4. Fill in the fields below and click Connect

Security note: the token is stored in this browser. Use a private repo and a fine-grained token limited to that one repo only. Anyone with admin access to this app on this device can read the token.
